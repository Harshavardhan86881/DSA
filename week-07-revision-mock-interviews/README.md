# Week 7 — Revision, mixed practice, mock interviews, final assessment

**Status: structure ready; lesson content NOT generated.**
Scope is fixed here; the revision packs, mocks and final assessment are generated after Weeks 1–6
exist, because they must draw on that material.

## 1. Learning objectives

By the end of Week 7 you can:

1. Recall every week's core patterns and their complexities without notes.
2. Pick the right pattern for an unfamiliar statement within two minutes, and say why.
3. Solve mixed-topic problems at interview speed (about 25–30 minutes each) without hints.
4. Complete a full mock interview: clarify requirements, plan aloud, code, test, and discuss
   complexity and trade-offs.
5. Explain your solutions in clear English, including a short walkthrough on a small example.
6. Identify and repair your remaining weak topics using the trackers from the earlier weeks.
7. Pass the final assessment covering Weeks 1–6.

## 2. Prerequisites

- Weeks 1–6 gates passed, or specific weaknesses identified and scheduled for repair in this week.
- Completed problem tracker and mistake notebook from all previous weeks (they determine what this
  week focuses on).

## 3. Planned topics

| # | Topic | Core idea |
| --- | --- | --- |
| 1 | Spaced repetition sweep | Re-run R3/R4 reviews for every topic from Weeks 1–6 |
| 2 | Pattern-recognition drills | Given ~40 statements, name the pattern, data structure and complexity in under a minute each |
| 3 | Mixed problem sets | Timed sets that combine topics instead of practising one pattern at a time |
| 4 | Speed and accuracy | Time-boxed solving with a written plan before code; logging minutes per problem |
| 5 | Mock interviews | Three full mocks: one easy-focused, one intermediate, one with follow-ups and pressure |
| 6 | Communication polish | Three-part verbal answers, clarifying questions, handling hints and feedback |
| 7 | Final assessment | Cumulative written test plus two live-style problems |
| 8 | Next-step planning | Choose the next specialisation or platform practice plan after this course |

## 4. Planned deliverables

| Folder | Planned contents |
| --- | --- |
| `lessons/` | Revision summaries per week (one page each: patterns, complexities, pitfalls) and a pattern-selection decision guide |
| `examples/` | Compact reference implementations of every pattern covered in the course, runnable as a self-check |
| `exercises/` | Mixed timed sets, with answer keys kept separate from the sets |
| `problems/` | Cross-topic problem list: each entry tagged with the patterns it needs, with solutions |
| `interview-prep/` | Three full mock interviews (interviewer script, problem, expected reasoning, evaluation notes) and a communication rubric |
| `revision/` | A complete flashcard deck for Weeks 1–6, an active-recall question bank, and a final spaced-repetition calendar |
| `assessments/` | Final assessment paper, answer key, and grading rubric with pass/fail bands |

## 6. Exit criteria

- [ ] Every topic from Weeks 1–6 has a completed R4 review.
- [ ] Three mock interviews completed, each with a written self-evaluation.
- [ ] Pattern-selection drill score above the target in the assessment rubric.
- [ ] Final assessment passed, and every failed item scheduled for repair.
- [ ] A written next-step plan exists (what to practise next, on which platform, and why).
