# Week 1 Cumulative Assessment

**Time limit:** 45 minutes. **No notes, no internet.** Write your solutions in Python 3.

## Instructions

1. Read all questions first (2 minutes).
2. Solve them in order; each is worth 10 points (total 50, plus 10 for explanations).
3. Write at least one test for each solution.
4. State time and space complexity for each solution.
5. After finishing, self-grade with the rubric below and record your score.

## Questions

### Q1 — Reverse an Array (10 pts)

Write `reverse_in_place(nums)` that reverses a list in place. O(n) time, O(1) space.

### Q2 — Second-Largest Distinct (10 pts)

Write `second_largest(nums)` returning the second-largest distinct value or `None`.

### Q3 — Two Sum (10 pts)

Write `two_sum(nums, target)` returning indices of the pair that sums to target.

### Q4 — Valid Palindrome (10 pts)

Write `is_valid_palindrome(s)` ignoring case and non-alphanumeric characters.

### Q5 — Maximum Subarray (10 pts)

Write `max_subarray(nums)` returning the maximum contiguous subarray sum (0 for empty).

### Q6 — Explanations (10 pts)

For Q3 and Q5, write the three-part spoken answer: idea, correctness + complexity, walkthrough
on a small input.

## Rubric (per question, 10 pts)

| Criterion | Points |
| --- | --- |
| Correct on the provided examples | 3 |
| Handles edge cases (empty, single, negatives, duplicates) | 3 |
| States correct time and space complexity | 2 |
| Code is clean and readable | 2 |

Q6 is graded on: clear idea (4), correct complexity (3), accurate walkthrough (3).

## Passing score

40 / 60 or higher. Below 40, repeat the weak topics with R1 reviews.
