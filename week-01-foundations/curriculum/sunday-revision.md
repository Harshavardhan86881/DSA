# Sunday — Week 1 Revision and Assessment

| | |
| --- | --- |
| **Week** | 1 — Foundations |
| **Theme** | Revision and assessment |
| **Estimated time** | 4 hours (60 + 75 + 60 + 45 + 15) |
| **Prerequisites** | Days 1–6 completed |
| **Deliverable** | Completed assessment in `assessments/` with self-graded score |

## 1. Day objectives

By the end of today you can:

1. Re-solve selected problems from a blank file under a timer.
2. Answer all Week 1 flashcards in under 2 seconds each.
3. Explain three solutions aloud in under 3 minutes each.
4. Complete the cumulative assessment and self-grade with the rubric.
5. Identify weak topics and plan extra reviews.

## 2. Four-hour block

| Block | Time | Task |
| --- | --- | --- |
| Mistake review (60 min) | Read mistake notebook; re-solve each bug's problem with the fix in mind. |
| Re-solving (75 min) | Re-solve 2–3 problems chosen by weakness, from a blank file, with a timer. |
| Retention testing (60 min) | Flashcards and active-recall questions for the whole week; explain 3 solutions aloud. |
| Cumulative assessment (45 min) | Complete `assessments/sunday-cumulative-assessment.md`, self-grade with rubric. |
| Planning (15 min) | Fill in `progress/` tracker; choose topics needing extra R1/R2 reviews. |

## 3. Mixed practice problems

Use these for the re-solving block (solutions already exist in `problems/` and `exercises/`):

1. Reverse an Array — in place, O(1) space.
2. Find the Second-Largest Distinct Element — single pass.
3. Running Sum of 1D Array — prefix sums.
4. Two Sum — hash map of complements.
5. Best Time to Buy and Sell Stock — running minimum.
6. Valid Palindrome — two pointers.
7. Valid Anagram — frequency counting.
8. Contains Duplicate — set membership.
9. Majority Element — counting and verification.
10. Maximum Subarray — running sum reset.

## 4. Active recall

Use `revision/flashcards.md` and `revision/active-recall.md`. Anything you cannot answer in 2
seconds becomes a new flashcard for the next day.

## 5. Assessment

Complete `assessments/sunday-cumulative-assessment.md` and self-grade with its rubric. Record
the score in `progress/`.

## 6. Reflection checklist

- [ ] Which topic took the longest to solve?
- [ ] Which edge case did you forget most often?
- [ ] Which complexity did you state incorrectly?
- [ ] Which problem would you re-solve tomorrow?
- [ ] What will you review in 3 days (R2)?

## 7. Exit criteria for Week 1

- [ ] All 6 lesson topics read, annotated and recalled without notes.
- [ ] Every exercise attempted before its solution was opened.
- [ ] All problems solved unaided at least once.
- [ ] Complexity stated correctly for each solution.
- [ ] Mistake notebook has an entry for every bug over 10 minutes.
- [ ] Flashcards answered in under 2 seconds each.
- [ ] Three solutions explained aloud in under 3 minutes each.
- [ ] Sunday cumulative assessment passed per rubric.
