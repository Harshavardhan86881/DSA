# Week 6 Revision Guide

- Backtracking: choose, explore, undo; copy path; state counts.
- Pruning: reject safely; sorting can enable pruning; not guaranteed big-O.
- Greedy: local choice, proof, counterexamples; activity selection sorts by finish time.
- DP: state, recurrence, base case, order, complexity.
- Memoization: top-down cache.
- Tabulation: bottom-up table.
- Coin change: dp[0]=0; greedy can fail.
- LIS: O(n^2) with strict `<`.
