# Week 6 Mistake Log

For each mistake, record:

1. Failing input.
2. Expected result.
3. Actual result.
4. Root cause.
5. Corrected reasoning.
6. A similar problem to retry later.

Common Week 6 mistakes:

- Missing `path.pop()`.
- Storing `path` instead of `path[:]`.
- Wrong DP base case.
- Wrong fill order.
- Greedy without a counterexample test.
