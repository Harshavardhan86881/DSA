## 1. Problem statement

Given an integer array `nums`, return all possible subsets (the power set). The solution may include duplicate subsets if input values repeat, because subsets are generated by position.

Function contract: `subsets(nums: list[int]) -> list[list[int]]`.

## 2. Constraints

- `1 <= len(nums) <= 10`
- `-10 <= nums[i] <= 10`
- Values may repeat.

## 3. Examples

Input: `nums = [1,2,3]`
Output: `[[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]`.

Input: `nums = []`
Output: `[[]]`.

## 4. Hints

<details><summary>Hint 1</summary>
At each index, choose to include or exclude the element.
</details>

<details><summary>Hint 2</summary>
Use a start index to avoid duplicate orderings.
</details>

<details><summary>Hint 3</summary>
Record a copy of the current path at every node.
</details>

## 5. Brute-force approach

Generate all 2^n subsets by bitmask. This is simple but does not teach the backtracking pattern.

## 6. Optimised approach

Backtrack with `start`. At every node, record the current subset. Then try each element from `start` onward.

Important code lines:

- `result.append(path[:])`: record at every node.
- `for i in range(start, len(nums))`: choose next element.
- `backtrack(i + 1, path)`: avoid reuse.
- `path.pop()`: undo.

## 7. Complexity analysis

- Time: O(n * 2^n).
- Auxiliary space: O(n), excluding output.

## 8. Edge cases and tests

- Empty input returns `[[]]`.
- Single element.
- Duplicate values may produce duplicate subsets.
- n = 10 gives 1024 subsets.

## 9. Common mistakes

- Forgetting to record at every node.
- Storing a mutable reference.
- Forgetting `path.pop()`.

## 10. Follow-up questions

1. How would you return only unique subsets for duplicate values?
2. How would you count subsets without storing them?
3. How would you generate subsets iteratively?
